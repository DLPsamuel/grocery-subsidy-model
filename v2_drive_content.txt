P291: [Heading 2] 2.1  Goal 1 — Single-Store Subsidy Effect
P292: [normal] Output: ΔCS(s) curve for one store — shows welfare gain at every subsidy level from $0 to B.
P293: [normal] Step 1: Select representative store j*
Choose a store in a food-desert tract (e.g., lowest-income tract in CD2). All other store prices remain at baseline. Fix θ = 0.65.
P294: [normal] Step 2: Build Δp_j(s) function
Δp_j(s) = θ_j · s / Q_j. Build a grid: s_grid = np.linspace(0, B_max, 500).
P295: [normal] Step 3: Compute V_ij matrix (pre-subsidy)
For each income group i and store j: V_ij = β_q_i·q_j + β_v_i·v_j − β_p_i·p_j − β_d_i·d_ij. Store as matrix V_pre of shape (N_groups, J).
P296: [normal] Step 4: For each s in grid, compute ΔCS(s)
Update V_ij*_post = V_ij*_pre + β_p_i·|Δp_j*(s)|. Compute logsum_pre = log(Σ_k exp(V_ik_pre)) per group. Compute logsum_post = log(Σ_k exp(V_ik_post)) per group. ΔW_i = (1/β_p_i)·(logsum_post − logsum_pre). ΔCS = Σ_i ΔW_i · household_count_i.
P297: [normal] Step 5: Find threshold s*
s* = min{s : ΔCS(s) ≥ ΔCS_min AND Δp_j(s)/p_j ≥ 5%}.
P298: [normal] Step 6: Sensitivity on θ and β_p
Repeat for θ ∈ {0.40, 0.65, 0.85} and β_p scale ∈ {0.8, 1.0, 1.2}. Plot ΔCS(s) curves with confidence band.
P299: [normal] Step 7: Compare tax break vs. rent subsidy
Both use the same formula Δp_j = θ·s/Q_j, so the ΔCS(s) curve is identical. The difference is practical: which cost item (tax or rent) can the city actually reduce for this store? Report both instrument labels at the same s* value.
