# NYC Municipal Grocery Subsidy — Model Design

Interactive documentation for an optimization framework that allocates a city grocery subsidy across candidate retail food stores in NYC.

**Live site:** https://dlpsamuel.github.io/grocery-subsidy-model/

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output is written to `dist/`. GitHub Pages deploys automatically on every push to `main` via `.github/workflows/deploy.yml`.
