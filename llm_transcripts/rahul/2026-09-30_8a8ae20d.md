### 🤖 Claude  <sub>2026-09-30 12:42</sub>

"High case" means running the model a second time with the biggest believable revenue numbers, to see how much the answer changes.

We don't know each store's real sales. So instead of trusting one number, we pick three:

| Case | Rate | What it is | 9-store total |
|---|---|---|---|
| **Low** | ReferenceUSA | Guesses based on worker counts; lowest | $27.2M |
| **Main** | $829/sq ft | Average for all Bronx grocery stores, bodegas included | $56.8M |
| **High** | $1,092/sq ft | Same Census method, but supermarkets and grocers only, no bodegas or convenience stores | $74.9M |

**Why supermarkets-only counts as "high":** bigger stores usually sell more per square foot than bodegas. So for Key Food or Food Fair, the real figure is probably closer to $1,092 than $829.

**Why run all three:** revenue sets how many baskets a store sells (Q_j). That decides how big a price cut a subsidy buys (price cut = θ × subsidy ÷ Q_j).
- More revenue means more baskets, so each basket gets a smaller cut.
- If the best store to subsidize is the same in all three runs, the answer is solid.
- If it changes, we have to say that the answer depends on revenue.

This check is called a **sensitivity test**. The model already does the same thing for κ (low, base and high).
